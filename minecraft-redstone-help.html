MINECRAFT • REDSTONE

Redstone without the headache.

A quick reference for building reliable circuits and finding the reason a contraption stopped working.

Signal basics

Redstone power travels through powered components and dust. Redstone dust has a signal strength from 15 down to 0, losing strength as it travels through dust.

Use a repeater when you need to refresh a signal or add delay.

Repeater

Repeaters refresh a redstone signal and can add a configurable delay. They are also useful for controlling direction in many circuits.

Comparator

Comparators can compare or subtract signals and can read container fullness. They are especially useful in item sorters, storage systems, and automation.

Pistons

Sticky pistons can pull blocks back when they retract. Check block movement limits and make sure the piston receives the intended pulse.

Common redstone failures

  • Check that the component actually receives power.
  • Look for a repeater facing the wrong direction.
  • Check whether a dust line has lost signal strength.
  • Make sure the powered block is the block you intended.
  • For clocks, verify that the circuit is not permanently powered.
  • Test complicated builds one section at a time.

Useful command checks

For command-based redstone builds, test your command in chat first, then place it in the command block.

/gamerule commandBlockOutput false
