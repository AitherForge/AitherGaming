Minecraft Help

Quick help for commands, command blocks, teleporting, effects, items, gamerules, and common Java/Bedrock command tasks.

Command basics

Commands normally start with /. Use /help to see commands available in your edition and version.

/help/help teleport/help give

Command syntax can differ between Java Edition and Bedrock Edition.

Teleport

/tp @s 100 64 100/tp @a 0 80 0

@s = yourself, @p = nearest player, @a = all players, @r = random player, @e = entities.

Give items

/give @s minecraft:diamond 64/give @p minecraft:command_block 1

Item IDs and advanced item syntax vary by edition/version.

Gamemode

/gamemode creative @s/gamemode survival @s/gamemode adventure @s/gamemode spectator @s

Effects

/effect give @s minecraft:speed 60 1/effect clear @s

Effect syntax differs between Java and Bedrock.

Weather & time

/weather clear/weather rain/time set day/time set night

Gamerules

/gamerule keepInventory true/gamerule doDaylightCycle false/gamerule doMobSpawning false

Gamerule names available to you depend on your edition and version.

Command blocks

Get one with:

/give @s minecraft:command_block 1

Place it, enter a command without the leading /, then power it with redstone. Chain and repeating blocks can automate command systems.

Selectors

@s — yourself@p — nearest player@a — all players@r — random player@e — entities

Useful commands

/locate structure minecraft:village_plains/setworldspawn/spawnpoint @s/kill @e[type=minecraft:item]
