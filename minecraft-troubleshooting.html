TROUBLESHOOTING

Fix it fast.

Start with the symptom, then work down the list.

Game will not load

  1. Refresh the page.
  2. Try a private/incognito tab.
  3. Disable extensions that block scripts or frames.
  4. Check your connection and wait for the game assets to finish loading.
  5. If only one game fails, return to the library and try another game.

Controls do not work

  1. Click or tap the game once so it has focus.
  2. Try the keyboard controls shown by the game.
  3. On mobile, use the game's touch controls when provided.
  4. Reload if a previous tab left keyboard focus in another element.

Lag or low FPS

  1. Close unnecessary tabs and apps.
  2. Lower the game's graphics settings if available.
  3. Keep the device cool and connected to power when appropriate.
  4. Try another browser if the problem is browser-specific.

Minecraft command failed

Check Java vs Bedrock syntax, selector spelling, coordinates, and permissions. Use the Command Generator to build a fresh command.
