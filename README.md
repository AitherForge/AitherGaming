# Aither Gaming

Aither Gaming is a fast, mobile-friendly browser game hub for Aither Forge.

## Game library

The launcher currently contains **exactly 100 games**:

- 12 games from the AA Gamerz Games collection.
- 88 games linked from the Ultimate Game Stash (UGS) game assets collection.
- Games are opened from their published locations instead of being recreated or rewritten by Aither Gaming.

## Included source integrations

- **Eaglercraft Extras** — `x8rr/Eaglercraft-Extras`. It provides Eaglercraft clients, worlds, servers, resource packs, skins, and guides. Its repository includes an AGPL-3.0 license.
- **AA Gamerz Games** — `aa-gamerz22/aa-gamerz-games`. A browser-game collection used here through links to its published games.
- **Ultimate Game Stash** — the supplied UGS Google Doc, with the UGS game assets collection used for the 88-game UGS section.
- **Google Drive folder** — supplied as a project source.
- **Google Drive file** — supplied as a project source.

## Architecture

Aither Gaming is a static GitHub Pages site. Third-party games are linked from their published locations rather than copied into this repository when redistribution terms are not confirmed. This keeps the launcher lightweight and avoids making or modifying the games themselves.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

Expected URL:

`https://aitherforge.github.io/AitherGaming/`
