# Aither Gaming

Aither Gaming is a fast, mobile-friendly browser game hub for Aither Forge.

## Included source integrations

- **Eaglercraft Extras** — `x8rr/Eaglercraft-Extras`. It provides Eaglercraft clients, worlds, servers, resource packs, skins, and guides. Its repository includes an AGPL-3.0 license.
- **AA Gamerz Games** — `aa-gamerz22/aa-gamerz-games`. A browser-game collection used here through links to its published GitHub Pages games.
- **Google Drive folder** — supplied as a project source.
- **Google Drive file** — supplied as a project source.
- **Google Doc** — supplied as a project source.

## Architecture

Aither Gaming is a static GitHub Pages site. Third-party games are linked from their published locations rather than copied into this repository when redistribution terms are not confirmed. This keeps the launcher lightweight and preserves attribution.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

Expected URL:

`https://aitherforge.github.io/AitherGaming/`
